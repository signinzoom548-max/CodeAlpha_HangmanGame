# Hangman Game

## Description
This is a simple text-based Hangman Game built using Python.

## Features
- Random word selection
- 6 incorrect guesses allowed
- User guesses one letter at a time
- Win or lose message displayed

## Technologies Used
- Python

## How to Run
1. Open the project in VS Code.
2. Run `hangman.py`.
3. Enter letters to guess the word.
